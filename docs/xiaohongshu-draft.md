# 小红书发布文案

标题：小红书笔记转JSON，分享个工作流

分享一个自己整理的 Automa v5 工作流，用浏览器把关键词下的笔记整理成 JSON，方便后续做资料整理。

这次实际跑了「澳洲申博、澳洲博士」两个关键词，每词设 10 篇，导出 20 篇；检查后 20 个笔记链接没有重复，两份导出文件的链接也完全对应。

怎么用：
① Chrome 扩展商店搜索 Automa 并安装
② 打开 Dashboard → Import workflow
③ 导入仓库里的 red_note_v5.json
④ 先登录小红书网页版，再点运行
⑤ 填关键词和每词篇数，等待下载两份 JSON

建议第一次只用 1 个关键词、3 篇，确认正常再调整。多个关键词可以用逗号分隔。默认使用搜索结果原排序；需要最新排序时，可自行接上保留的「筛选／最新」节点，教程有接线说明。

字段包括关键词、标题、正文、图片链接、页面时间、已加载的评论区域和原笔记链接。这次标题和正文都有值，17 篇采到评论，3 篇未采到。图片和评论都不是全量采集。
