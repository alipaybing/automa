# 小红书发布文案

标题：把小红书经验交给AI，帮我做功课

出国、留学、在国外生活，很多具体问题的答案，藏在小红书的亲身经历里。

比如学校的真实体验、租房避坑、生活成本、申请时间线。这些信息很有参考价值，但分散在不同笔记和评论中，一篇篇翻、反复比较很花时间。

直接问 AI，它未必掌握这些细节；让它在线搜索，也不一定能读到需要登录才能查看的内容。

所以我整理了一个工作流：先收集自己想了解的小红书资料，再交给大模型分析。

怎么用：
① Chrome 安装 Automa，导入仓库里的工作流
② 登录小红书，设置关键词和笔记数量
③ 脚本导出笔记正文、链接等 JSON 资料
④ 上传给你常用的大模型，围绕自己的问题提问

例如搜索「澳洲申博、澳洲博士」，可以让 AI：
· 汇总申请经验，整理时间线和准备清单
· 比较不同说法，找出共识、分歧和适用条件
· 标记疑似中介推广、广告或缺少依据的结论，并说明理由
· 为每条结论保留原笔记链接，方便回去核对

小红书提供具体经验，大模型负责归纳分析，自己核对关键结论。希望把零散的信息整理成能帮助判断的资料，少花一些重复翻帖的时间。

这次实测两个关键词，每词 10 篇，共导出 20 篇。第一次建议只试 3 篇。图片和评论不是全量采集；「筛选／最新」默认不连接，需要时按教程自行接线。

广告识别只作为线索。涉及申请、签证、费用等重要信息，仍要回到原文和官方渠道核实。
